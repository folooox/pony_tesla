## 主要交互

| 操作 | 预期结果 |
| --- | --- |
| 启动并切换车辆、行程、充电、我的 | 4 个系统导航入口可用，清楚标示演示状态，无真实控车 |
| 车辆 → 右上角菜单 → 编辑首页控制 | 可以增删和拖动排序，最多 4 个；清空后不自动补回 |
| 结束 App 进程再打开 | 快捷控制顺序保留；模拟历史重新生成 |
| 执行锁车、空调或哨兵操作 | 系统确认框；等待模拟服务后更新，结果提示与操作记录对应；等待时不能重复执行 |
| 打开全部控制、空调及车辆设置子入口 | 导航和返回正常；未实现的功能说明清楚，不显示下发成功 |
| 行程列表切换日期 | 列表对应所选日期；顶部明确为最近 7 天总计；无数据日期显示空状态 |
| 打开行程，拖动曲线和时间滑块 | 地图位置、数值和时间轴同步；速度、功率、电量可切换 |
| 播放、暂停、离开行程详情或切入后台 | 回放开始/暂停正确，离开页面或后台停止 |
| 行程 → 标签与备注 → 保存并重新打开 | 当前演示会话保留内容；超过长度限制不能提交 |
| 导出单段或全部行程 CSV | 系统文件导出完成，包含模拟标记和对应记录；中文、逗号、引号和换行未破坏列 |
| 充电页面调整上限 | 只改变待应用值，按应用并得到结果后才改变车辆上限 |
| 暂停/开始模拟充电 | 系统确认后更新状态；暂停时动画停止，日志有相应结果 |
| 我的 → 行程管理与导出 → 清空模拟历史 | 确认后行程、充电记录和操作记录清空，下拉刷新不会恢复；重置演示才重新生成 |
| 车辆 → 定位地图 → 搜索地点 | 联网时显示真实地图搜索结果；空查询清除结果，离开取消请求；发送导航仍显示未接入 |

## 异常场景

在“我的 → 模拟器测试”中切换，或设置 scheme 参数 `-scenario <值>`。

| 场景 | 预期结果 |
| --- | --- |
| empty | 行程和充电历史为空，可理解的空状态，无虚构汇总值 |
| asleep | 显示休眠说明，控制禁用，不伪造唤醒成功 |
| offline | 明确缓存/离线状态，控制禁用，不将缓存时间刷新为实时 |
| error | 错误页与重试入口；重试后仍失败直到切换正常场景 |
| expired | 显示需要重新授权；原生真实登录入口尚未开放 |
| missingData | 缺失值显示“—”；缺口不连地图或曲线；缺失时刻不编造数值；不支持的首页控制隐藏 |
| 快速连续切换多个场景 | 最后选择生效；先前请求不能覆盖新场景的结果或错误 |
| 正常场景静置超过 2 分钟 | 数据过期后禁用控制并提示刷新；下拉刷新后恢复 |

## 系统外观与辅助功能

- 浅色/深色：系统字体、语义颜色和图表均清晰；系统栏与 glass 按钮呈现原生材质。
- 滚动：Tab bar 与行程导航栏的系统折叠行为正确，底部内容不被遮挡。
- 最大辅助功能字号：指标纵向排列，曲线选择使用菜单；主要按钮可达，标题和中文不被严重截断。
- VoiceOver：页签、控件名称和指标单位可理解；缺失值读为数据不足。
- 减少动态效果：回放自动播放禁用，可手动查看；充电脉冲停止。
- 减少透明度/增加对比度：系统材质响应，文字和禁用状态可辨识。
- 小屏 iPhone、横屏及 iPad：无固定画布、伪造状态栏；表单、sheet、导航和工具栏可用。
- 截取四个主页面的原生截图，标注模拟器型号及系统版本，不能用旧网页截图替代。

账号连接、真实车辆能力、指令回执、服务端采集和保留策略需要后续单独联调；本清单仅覆盖当前模拟版本。
