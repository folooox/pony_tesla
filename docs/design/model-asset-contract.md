# 车辆与主题 3D 资产制作规范

状态：正式资产制作约定，当前还没有生产级 USDZ；程序化样机位于 `ios/Pony/VehicleScene.swift`。以下加载验证与性能预算尚待实现和实测，不是已通过的指标。

## 交付内容

每个车型／主题提供原始 DCC 工程、可在 RealityKit 导入的 USDZ、纹理、命名节点清单、预览转台视频、来源及使用范围。整车只有一张网格而不能拆门的资产不满足要求。工作单位米，Y 向上，车头朝 -Z，车辆左侧为 -X；车底接近 Y=0，轮距和轴距以所选车型实测／可靠规格为准。

先做国产 2022 Model 3 的一致配置。车漆、黑白内饰、轮毂作为资产变体，不混用不同年份结构。完整内饰至少包含仪表台、饰条、方向盘、中控屏、中央通道、五个座位、门内板、门槛、前后舱内腔。

## 必需节点

| 节点 | 用途 |
| --- | --- |
| `vehicle` | 模型根节点；只接受展示旋转，不接受真实业务状态 |
| `hinge_frontLeft` / `frontRight` / `rearLeft` / `rearRight`（每项完整前缀 `hinge_`） | 独立车门铰点，包含外门板、内门板、对应玻璃 |
| `hinge_frunk` / `hinge_trunk` / `hinge_chargePort` | 舱盖与充电口铰点，旋转不会带动不相关车身 |
| `seat_frontLeft` / `frontRight` / `rearLeft` / `rearCenter` / `rearRight`（完整前缀 `seat_`） | 每座独立加热遮罩；座面与靠背分区 |
| `steering` | 方向盘加热区域 |
| `glass_roof` / `side_glass` / `headlamp` / `taillamp` | 玻璃与灯光独立材质；同名多实例需在资源清单按完整路径区分 |

正式管线应使用完整路径映射，不能依赖全局模糊名称搜索。需要在加载时检查必需节点、单位、坐标方向和材质；错误资产显示明确失败状态并保留当前可用模型。IP 资产允许没有实车同构节点，通过主题适配表显式转译，并保留实车控制层。

## 材质与机构

- PBR 车漆、玻璃、塑料、金属、橡胶、皮革、木饰条分开，不把阴影烘焙进车漆底色。
- 原点放在实际铰链位置；开放角度由模型清单定义，不能将样机示意角作为真实规格。
- 关闭时接缝贴合，打开时无穿模；前后备箱保留内腔；五座内饰不能通过透明车顶露出空壳。
- 玻璃必须验证多层排序。座舱切换由展示层剖切／隐藏外壳完成，不修改任何开合传感器状态。
- 加热使用独立遮罩／材质参数。气流是独立特效节点，跟随座舱布局，不硬编码到首页坐标。

## 初始性能预算（待目标真机实测调整）

近景模型先以 80k–150k 三角面、2K 主纹理为制作预算，生成至少一个简化 LOD。以目标最低支持设备为验收设备，稳定交互优先于超高贴图分辨率。首屏先出现原生车况和控件，模型异步加载；切后台停止特效；低电量与 Reduce Motion 降低持续动画。记录 GPU 帧时间、峰值内存、资源加载时间和 10 分钟温升后再锁定预算。

## 美术签收镜头

前侧 3/4、正前、正侧、后侧 3/4、座舱俯视、前备箱打开、后备箱打开、四门分别打开、全部打开。深浅背景各检查一次，另检查加热与气流叠加。正式签收以实际 iOS 渲染为准，离线建模器渲染图仅作参考。
