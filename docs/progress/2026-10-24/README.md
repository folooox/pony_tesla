## 本次代码范围

基于 `0d1c2a5eeb1d663e7334086546bdf0c6cc39ecde`，保留已有官网直接登录修复，并包含车辆名称、只读失败分类的本地修复，以及登录后至多一次唤醒与有限车况读取。本次不覆盖 main，不合并暂停的配对/其他控车/采集方案。

- 手机：`NativeTeslaClient.swift`、`NativeAccountViews.swift`、`PonyApp.swift`。账号和车辆共享进度；目标确定后六十秒总上限，最多四次只读在线确认，在线后一次车况读取。恢复、续期、手动读缓存/车况不唤醒；停止等待不能撤销已受理命令。
- 核心：`ReadOnlyVehicleData.swift` 及测试，包含名称回退、精确缓存缺失/离线提示等已有修复。未知字段不冒充零、演示值或实时数据。
- 最新界面文案与日夜辅助文字颜色已改，但尚未重跑完整页面验证与最终归档。
- 最新导航修复已写入：已确认登录失效时，车辆/行程/充电保持原生失败页面及导航身份，不退回演示车辆；原生展示标志到成功重新登录或显式退出时才重置。该修复未被最终运行验证证明。

PONY 已明确接受更广控制授权；这不是“仅唤醒”权限，仍涵盖解锁等操作。Pony 本次仅用一次唤醒，不开放其他控制。官方授权由本人完成，部署/重启/替换预览另行确认。
