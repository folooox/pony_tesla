# 第一版 UI 原型

> 已弃用的视觉方向：用户明确要求 iOS 27 原生 Liquid Glass 与系统字体。本页及 `screenshots/` 仅保留历史参考，不代表当前设计。当前实现转向 [原生 SwiftUI 工程](../ios/README.md)，尚待 Xcode 编译和原生截图验证。

2026-10-13。面向 iOS 的视觉与交互预览，尚不是原生 iOS 应用，也未接入真实车辆。

## 四个主要入口

- **车辆**：2022 款 Model 3 造型示意、电量与续航、可编辑快捷控制、空调、找车和车况设置。
- **行程**：最近 7 天、区间汇总、每段行程的地图/里程/时长/能耗；点进详情查看地图与速度、功率、电量曲线布局。
- **充电**：电量进度、充电功率、充入电量、时长、上限、暂停与预约、历史记录；不展示费用。
- **我的**：车辆授权、首页布局、操作记录、7 天云端数据管理、导出、隐私和偏好。

视觉采用暖白背景、墨绿主色、浅橄榄绿辅助色，优先突出状态、数字和地图。首页车图为手绘矢量示意，并非车辆官方渲染资产；地图也是示意，未引入真实地图服务。

## 查看与截图

可直接在浏览器打开 `prototype/index.html`；也可以仅对本机运行静态服务：

```sh
python3 -m http.server 8790 --bind 127.0.0.1 --directory prototype
```

- 总览：`http://127.0.0.1:8790/?view=board`
- 单页：`?page=vehicle`、`trips`、`charging`、`profile`、`detail`
- 已生成的截图位于 `screenshots/`，包括 `overview.png` 和五张单页图。

重新渲染截图：

```sh
node prototype/capture.mjs
```

脚本使用临时本地静态服务和 Chromium，检查无横向溢出、页面切换、快捷按钮选择及保存、详情曲线切换、充电上限滑块、数据管理弹层。不会调用 Tesla API，也不读取任何后台密钥。

## 原型交互的边界

所有账号、车辆、电量、充电和行程数据均为示例。控车按钮只打开交互说明，不发送指令。快捷控制的显示选择可保存在当前浏览器；地图、曲线和回放用于展示布局，完整数据联动还未实现。桌面 Chromium 的手机尺寸截图不等于 iOS 实机测试。

原型独立于已部署的连接测试后台，此次没有替换线上登录页面。
